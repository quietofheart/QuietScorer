## 简体中文

完全免费、无广告的安卓计分器软件，可用于台球、棋牌等娱乐计分。

### ✨ 功能特性

- 🎱 **多种计分场景**：台球（中式黑八、斯诺克等）、棋牌及各类娱乐计分
- 📊 **比赛历史**：自动保存每场比赛的完整记录，随时回顾
- ⏸️ **中途退出不丢分**：切后台或意外退出后自动恢复比赛进度
- 🌐 **多语言支持**：简体中文 / 繁體中文 / English
- 🔒 **隐私安全**：所有数据仅保存在本地，无任何联网上传、无广告、无追踪
- 📴 **完全离线**：安装后无需网络即可使用全部功能
- ⚡ **省电优化**：低功耗模式，长时间计分不发热

## English

A completely free, ad-free scorekeeping app for Android — perfect for billiards, card games, and all kinds of recreational scoring.

### ✨ Features

- 🎱 **Multiple scoring scenarios**: Billiards (Chinese Eight-Ball, Snooker, etc.), card & board games, and general recreational scoring
- 📊 **Match history**: Every match is automatically saved in full — review it anytime
- ⏸️ **Never lose your score**: Match progress is automatically restored after switching apps or an unexpected exit
- 🌐 **Multilingual**: Simplified Chinese / Traditional Chinese / English
- 🔒 **Privacy-friendly**: All data stays on your device — no uploads, no ads, no tracking
- 📴 **Fully offline**: All features work without any network connection after installation
- ⚡ **Battery-friendly**: Low-power mode keeps the device cool even during long scoring sessions

### 📥 Download & Install

Download the latest APK from the [Releases](../../releases) page.

**System requirements**: Android 7.0 or above (arm64 devices)

> If your device warns about "unknown sources" during installation, simply allow installs from that source in system settings.

### 🚀 Quick Start

1. Open the app and pick a rule set (or just use the default)
2. Start scoring — one tap per score
3. After the match, check the full record under **History**
